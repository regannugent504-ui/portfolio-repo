About

I'm Regan Nugent, a student at Texas Christian University. This semester, in Multimedia Authoring: Mobile Apps and eBooks (WRIT 40363), I went from writing my first HTML page to deploying interactive web apps on GitHub Pages.

The biggest shift was learning to build in layers: structure first with HTML, then style with CSS, then behavior with JavaScript. I also learned to commit often, test on real screens, and treat accessibility as part of the build rather than a final check. In the last project, I learned how to work with AI as a collaborator while still understanding every line I ship.

Projects

The projects are listed in the order I built them, so you can see my skills grow from one to the next.

  1. Project 1: Original Portfolio

    My first personal site, built from scratch with semantic HTML and hand-written CSS. It introduced me to page structure, styling, and publishing a site online. This page you're reading is its next version.

    Technologies: HTML, CSS, Git, GitHub Pages

  2. Project 2: Local Favorites Tracker

    A web app for saving and organizing favorite local spots. It adds, displays, and removes entries with JavaScript, and uses localStorage so the list is still there when you come back.

    Technologies: HTML, CSS, JavaScript, localStorage, GitHub Pages

  3. Project 3: Personal Data Dashboard

    A dashboard that pulls data from a JSON file into a weather widget and other panels. It includes a dark and light theme toggle and a layout that adapts to phone, tablet, and desktop screens.

    Technologies: HTML, CSS, JavaScript, JSON data, responsive design

  4. Project Zed: Reading Tracker

    A reading tracker planned and built with AI assistance. I wrote the plan, directed the AI, and tested and revised the code myself, so I could explain and change every part.

    Technologies: HTML, CSS, JavaScript, AI-assisted development
